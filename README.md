# Tennis Drill DB (site)

Static site that lets you browse, filter and search tennis drills and build practice sessions.

The content is a personal, condensed summary of coaching books by Human Kinetics (Pressure Tennis, Tennis Practice Games, The Tennis Drill Book). Each drill cites its book and page. The books are the property of their authors and publisher; buy them for the full text.

Source and build tooling live in a private repository.
